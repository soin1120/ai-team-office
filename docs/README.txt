=====================================================================
  AI 팀 사무실 — 설명서
=====================================================================

클로드(Claude Code), 코덱스(Codex CLI), 제미나이(Antigravity CLI)가
한 팀이 되어 일하는 프로그램입니다.
지시 하나를 팀장이 나눠 맡기면, 팀원들이 동시에 작업하고, 서로 인계하고,
검토까지 마친 뒤 짧은 보고서를 올립니다.
누가 무엇을 하는지는 3D 사무실에서 실시간으로 볼 수 있습니다.

AI는 셋 다 없어도 됩니다. 하나만 있어도 되고, 둘이나 셋이면 일을 나눠서 합니다.


---------------------------------------------------------------------
  📁 폴더 구성
---------------------------------------------------------------------

  AI팀사무실\
   ├─ AI팀사무실.exe      ← 이걸 실행합니다 (프로그램 본체, 이 파일 하나로 돌아감)
   ├─ README.txt          ← 지금 보고 있는 설명서
   └─ 규칙\
       └─ 팀규칙.md       ← 어느 PC에서나 똑같이 적용되는 팀 규칙

  내 문서\AI팀사무실\
   └─ 이PC메모.md         ← 이 PC에만 해당하는 메모 (처음 실행할 때 자동으로 만들어짐)

  왜 나눴나요?
   - 팀규칙.md는 프로그램과 같이 다니는 규칙이라 프로그램 폴더에 둡니다.
     다른 사람에게 폴더째 주면 규칙도 같이 갑니다.
   - 이PC메모.md는 "이 PC의 한/글 버전", "이 PC의 파이썬 경로"처럼 이 컴퓨터에만
     맞는 내용이라 내 문서에 둡니다. 프로그램을 새 버전으로 바꾸거나 폴더를 옮겨도
     그대로 남고, 다른 사람에게 폴더를 줘도 따라가지 않습니다.


---------------------------------------------------------------------
  ▶ 처음 실행하기 (초보용, 차근차근)
---------------------------------------------------------------------

  1단계. 폴더를 원하는 곳에 둡니다
     예) D:\Programs\AI팀사무실
     ※ 압축 파일(zip) 안에서 바로 실행하지 말고, 꼭 압축을 풀고 실행하세요.
       (압축 안에서 실행하면 규칙 파일을 저장할 곳이 없어 설정이 날아갑니다.)

  2단계. AI팀사무실.exe 를 더블클릭합니다
     파란 "Windows의 PC 보호" 창이 뜰 수 있습니다.
     → [추가 정보] → [실행] 을 누르세요.
     왜? 개인이 만든 프로그램이라 마이크로소프트 서명이 없어서 뜨는 경고입니다.
         한 번 실행하면 다음부터는 안 뜹니다.

  3단계. 팀원(AI) 준비 창이 뜹니다
     설치·로그인된 AI가 하나도 없으면 [팀원 준비] 창이 자동으로 뜹니다.
     (나중에 다시 열려면 화면 위쪽의 [⚙ 팀원 설정] 버튼)

     가장 쉬운 방법:
     → [🧰 빠진 팀원 한 번에 준비하기] 버튼 한 번.
       파란 PowerShell 창이 하나 열리고, 빠진 AI를 차례로
       "설치 → 로그인 창 열기"까지 알아서 진행합니다.
       화면에 "지금 무엇을, 왜 하는지"가 한 줄씩 나오니 읽으면서 기다리면 됩니다.

     한 명씩 하고 싶으면 각 팀원 칸의 [⬇ 설치하고 로그인하기] 를 누르세요.

     각 AI는 무엇을 설치하나요? (왜 필요한지)
     ┌──────────┬──────────────────────────────┬──────────────────────────┐
     │ 팀원     │ 설치되는 것                  │ 왜 필요한가요?           │
     ├──────────┼──────────────────────────────┼──────────────────────────┤
     │ 클로드   │ Claude Code (공식 설치 명령) │ 팀장 역할. 계획·지시서·  │
     │          │ 로그인: Claude Pro 이상      │ 검토·보고를 맡습니다.    │
     ├──────────┼──────────────────────────────┼──────────────────────────┤
     │ 코덱스   │ Node.js(없을 때만) +         │ 정확한 구현·수정·테스트. │
     │          │ Codex CLI                    │ Node.js는 코덱스가 돌아  │
     │          │ 로그인: ChatGPT Plus 이상    │ 가는 데 꼭 필요합니다.   │
     ├──────────┼──────────────────────────────┼──────────────────────────┤
     │ 제미나이 │ Antigravity CLI (agy)        │ 쉽고 양 많은 일 담당     │
     │          │ 로그인: 구글 계정            │ (모으기·세기·형식 맞추기)│
     └──────────┴──────────────────────────────┴──────────────────────────┘
     ※ Codex 데스크톱 앱만 있는 경우에도 CLI는 따로 설치해야 합니다.
       (앱 안의 codex는 다른 프로그램이 실행할 수 없게 잠겨 있어요.)

  4단계. 로그인 창에서 로그인합니다
     설치가 끝나면 로그인 창(또는 브라우저)이 열립니다. 평소 쓰는 계정으로 로그인하세요.
     ※ 비밀번호·인증 코드는 직접 입력하세요. 이 프로그램은 대신 입력하지 않습니다.
     다 끝나면 PowerShell 창을 닫으세요.

  5단계. 준비 창이 알아서 다시 확인합니다
     준비 창은 8초마다 설치·로그인 상태를 다시 봅니다.
     모든 칸이 초록색(✅)이 되면 끝. 바로 안 바뀌면 [다시 확인] 을 누르세요.

  6단계. (한/글·PowerPoint 작업을 할 때만) MCP 설치
     화면 맨 위에 노란 [MCP 설치·연결] 띠가 보이면 한 번 눌러 주세요.
     왜? AI가 한/글·PowerPoint 파일을 직접 읽고 고치려면 연결 도구(MCP)가 필요합니다.
         누르면 파이썬 패키지 설치 → MCP 설치 → 세 AI 모두에 등록까지 한 번에 합니다.
     ※ 파이썬이 없으면 먼저: winget install Python.Python.3.11
     ※ 한/글·PowerPoint 프로그램 자체는 각자 설치되어 있어야 합니다.

  ※ 프로그램 창은 크롬으로 열립니다(주소창 없는 앱 창). 크롬이 없으면 엣지로 열립니다.
    왜 크롬? 만든 웹페이지 결과물도 크롬으로 바로 띄워 같은 화면에서 확인하기 위해서예요.

  7단계. 첫 지시를 해 봅니다
     왼쪽 위 [＋ 새 대화] → 아래 입력칸에 지시 → Enter.
     예) "내 문서\테스트 폴더에 오늘 날짜로 회의록 양식 만들어줘"
     작업 폴더는 입력칸 근처의 [📁 작업 폴더] 버튼으로 고릅니다.


---------------------------------------------------------------------
  💬 쓰는 법
---------------------------------------------------------------------

  ■ 대화 (Claude 세션처럼)
   - 왼쪽 목록이 대화 목록입니다. 오래된 것 → 최신 순, 열면 맨 아래(최신)부터 보입니다.
   - 대화를 고른 채 입력하면 "그 대화에 이어서" 말하기입니다.
     팀은 그 대화 안의 내용만 기억합니다. 다른 대화 내용은 섞지 않습니다.
   - 새 일을 시킬 땐 [＋ 새 대화]. 아무것도 기억하지 않은 상태로 시작합니다.
   - Enter = 보내기, Shift+Enter = 줄바꿈.
   - 사진·파일: 입력칸에 끌어 놓거나 Ctrl+V. (한 번에 10개, 파일당 20MB)

  ■ 팀은 이렇게 일합니다
   1) 팀장이 지시의 크기를 봅니다. 간단하면 팀장이 바로 처리, 크면 팀 작업.
   2) 업무를 나눕니다. 업무마다 "가장 잘할 팀원"이 맡습니다(맡긴 이유도 표시).
      잘하는 팀원은 여러 업무를 동시에 맡을 수 있고(최대 3개), 팀장도 예외가 아닙니다.
        클로드 = 설계 판단·까다로운 글·검토
        코덱스 = 정확한 구현·수정·테스트
        제미나이 = 쉽고 단순하고 양 많은 일만 (복잡한 일은 맡기지 않음)
   3) 각자 일하고, 끝나면 다음 사람에게 인계 메모를 남깁니다.
   4) 검토합니다 (아래 참고).
   5) 짧은 보고서가 올라오고, 만든 결과물이 화면에 바로 뜹니다.
      (웹페이지 → 크롬, 한/글·PPT·엑셀·PDF → 기본 프로그램, 그 밖 → 폴더 열기.
       [⚙ 설정]의 '끝나면 결과 바로 띄우기'로 끌 수 있어요.)
        만든 것: 회사 매뉴얼을 매뉴얼 폴더에 작성해 저장해 놨어요.
        고친 것: …   남은 것: …   다음에: …
      자세한 내용은 [상세 보기]를 누르면 펼쳐집니다.

  ■ 검토
   - 간단: 일하지 않은 팀원 1명이 봅니다. (제미나이는 검토자로 고르지 않음)
   - 꼼꼼: 세 관점으로 동시에 봅니다.
       ① 요청·계획·규칙 (클로드) — 시킨 대로 했나, 팀 규칙을 지켰나
       ② 로직·예외·QA (코덱스)   — 직접 실행·테스트해서 확인
       ③ 단순 점검 (제미나이)     — 파일이 있나, 개수·빈칸·TODO·깨진 글자·경로
   - 문제는 CRITICAL / MAJOR / MINOR로 나누고, 근거(파일:줄, 실행 결과)를 꼭 붙입니다.
     근거 없는 큰 문제는 한 단계 낮춰지고, 같은 지적은 한 번만 셉니다.
   - CRITICAL·MAJOR만 원래 담당에게 돌려보내 고치게 합니다.

  ■ 로그 보기
   - 대화창 위 [보기] 막대: 전체 / 💬 대화 / 🧭 진행(배정·인계·완료·검토) / ⚠ 문제(우려·오류·위반·판정)
   - 팀원 이름 버튼으로 그 팀원 말만 숨기거나 보이기, [🔧 기술 작업]으로 파일 읽기·명령 실행 줄 보이기
   - 같은 팀원이 이어서 한 말은 한 덩어리로, 말마다 업무 번호(T1, T2…)가 붙고, 단계가 바뀔 때 구분선이 생깁니다.

  ■ MCP 먼저
   - 한/글·PowerPoint만이 아니라, 요청에 나오는 모든 프로그램(Unity, Blender, Photoshop 등)마다
     "MCP로 다룰 수 있나?"를 가장 먼저 생각합니다. 연결된 게 없으면 믿을 만한 MCP를 찾아 연결부터 합니다.

  ■ 클로드 앱의 프로젝트
   - [⚙ 설정] → 프로젝트 목록에 '🤖 클로드 앱의 프로젝트·작업 폴더'가 같이 보입니다.
     고르면 그 폴더로 바뀌고, 그 폴더에서 나눈 클로드 대화도 왼쪽 목록에 함께 보여요.
   - (프로젝트의 지침·첨부 파일은 claude.ai 서버에 있어 이 프로그램에서는 읽을 수 없어요.)

  ■ 객관적인 판단 ⚖
   - 팀원끼리 서로의 말을 그대로 믿지 않습니다. 인계 메모·검토 의견도 직접 열어 보고
     실행해 본 근거로만 판단합니다.
   - 검토 지적이 틀렸다고 생각하면, 고치는 팀원이 '반론 — 근거'를 남길 수 있습니다.
     다음 검토자는 누가 말했는지가 아니라 근거만 보고 '인정(지적 철회)' 또는 '유지'로 판정하고,
     그 판정과 이유가 로그에 ⚖로 남습니다.

  ■ AI 비서 드론 🛸
   팀원이 보조 에이전트(서브에이전트)를 띄워 일을 나눠 맡기면, 3D 사무실에서
   그 팀원 머리 위로 작은 드론이 날아다니며 책상 쪽으로 빛을 비춥니다.
   보조 일이 끝나면 드론은 사라집니다. (드론 수 = 동시에 돌아가는 보조 에이전트 수, 최대 3대)

  ■ 규칙 위반 🚨
   팀원이 남의 파일을 고치거나, 읽기만 해야 할 단계에서 파일을 고치거나,
   팀 규칙을 어기면 로그에 🚨로 크게 표시되고, 그 AI의 다음 지시 맨 앞에
   강한 경고가 붙으며, 최종 보고서에도 남습니다.

  ■ 사용량·근태
   - 남은 사용량은 각 AI의 공식 /usage로 받아옵니다 (토큰 안 씀).
   - 한도가 바닥나면 초기화 시각까지 휴가/반차/조기 퇴근을 가고,
     하던 일은 클로드 → 코덱스 → 제미나이 순서로 넘어갑니다. 팀장도 같은 순서로 교대.
   - 제미나이는 Gemini 한도만 바닥났으면 agy 안의 Claude 모델로 바꿔 계속합니다
     (카드에 '↻ 대체 모델' 표시).
   - 한도가 아닌 다른 이유로 막혀도(옵션 오류 등) 한 번 더 해 보고, 안 되면 다른 팀원에게 넘깁니다.
   - [⚙ 설정] → [🗓 팀원 근태]에서 직접 휴가·반차·조기 퇴근·재우기·복귀도 됩니다.

  ■ 관리자 권한
   관리자 권한이 필요해 막히면 모든 작업을 멈추고 창을 띄웁니다.
   [관리자 권한으로 이어서 하기] → UAC에서 [예] → 멈췄던 곳부터 이어서 끝냅니다.

  ■ 규칙 파일
   - 화면의 📏 규칙 버튼으로 메모장에서 열 수 있습니다. 고치면 다음 작업부터 반영.
   - 프로젝트별 내용은 작업 폴더의 AGENTS.md 에 적습니다.
   - 접속 주소·계정·비밀번호는 작업 폴더의 AGENTS.local.md 에 적습니다.
     화면·로그에서는 •••• 로 가리고, git에 올라가지 않게 자동으로 막습니다.
     단, 내용은 AI 회사(Anthropic·OpenAI·Google) 서버로는 전송됩니다.


---------------------------------------------------------------------
  🔄 새 버전으로 바꾸기 (업데이트)
---------------------------------------------------------------------

  가장 쉬운 방법: 화면 위쪽 [⬆ 업데이트] 버튼
   - 새 버전은 https://github.com/soin1120/ai-team-office/releases 에 올라옵니다.
   - 제작자가 새 버전을 올리면 버튼이 빨간색으로 깜빡입니다.
   - 누르고 [지금 업데이트] → 새 버전을 받아 바꾼 뒤 프로그램이 다시 켜집니다.
   - 팀이 일하는 중에는 끝난 뒤에 바꿉니다(하던 일이 끊기지 않게).
   - 팀규칙.md를 직접 고쳐 썼다면 덮어쓰지 않고 '팀규칙.새버전.md'로 옆에 둡니다.

  손으로 바꾸려면:
  1. 트레이(시계 옆) 아이콘 우클릭 → [종료]
  2. 새 AI팀사무실.exe 로 덮어쓰기
  3. 다시 실행

  업데이트해도 사라지지 않는 것 (프로그램 폴더 밖에 저장됨):
   - 대화·작업 기록 : 각 작업 폴더의 .aiteam\ 폴더
   - 이PC메모        : 내 문서\AI팀사무실\이PC메모.md
   - 프로젝트 목록·근태·캐릭터 꾸미기·화면 설정 : %LOCALAPPDATA%\AITeam\
   - 팀규칙.md       : 프로그램 폴더의 규칙\ (덮어쓰지 않으면 그대로. 고친 내용 유지)
   ※ 프로그램 폴더를 통째로 다른 곳으로 옮겨도 대화 목록은 그대로 보입니다.

---------------------------------------------------------------------
  🛠 자주 생기는 문제
---------------------------------------------------------------------

  증상                                   │ 해결
  ───────────────────────────────────────┼────────────────────────────────────────
  "Windows의 PC 보호" 파란 창            │ [추가 정보] → [실행]
  실행했는데 창이 안 보임                │ 트레이 아이콘 더블클릭 (이미 켜져 있을 수 있음)
  팀원 칸이 계속 빨간색(설치 안 됨)      │ 설치 창을 닫고 [다시 확인]. 그래도 안 되면 PC 재부팅
                                         │ (설치 직후엔 PATH가 새로 안 잡혀 있을 수 있음)
  '로그인 필요'로 나옴                   │ 그 팀원 칸의 [🔑 로그인하기]
  코덱스 설치에서 npm 오류               │ Node.js가 막 설치된 경우. 창을 닫고 버튼을 한 번 더
  노란 [MCP 설치·연결] 띠가 안 사라짐    │ 파이썬 설치 확인: winget install Python.Python.3.11
  한/글 파일을 못 읽음                   │ 한/글이 설치돼 있는지 + MCP 설치 띠를 눌렀는지 확인
  "관리자 권한 필요" 창                  │ [관리자 권한으로 이어서 하기] → UAC [예]
  팀원이 '휴가 중'                       │ 사용량 한도가 바닥남. 초기화 시각에 자동 복귀
  다른 대화 내용이 섞여 보임             │ 새 일은 [＋ 새 대화]로 시작
  압축 안에서 실행해서 설정이 날아감     │ 압축을 풀고 실행
